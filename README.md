# 🤖 Vision-Based Hand Guided JetBot

A lightweight computer vision project deployed on NVIDIA JetBot (2GB Jetson Nano).

The robot detects motion generated by human hand movement using real-time frame differencing and autonomously navigates toward the detected direction.

The system uses OpenCV-based motion analysis instead of heavy deep learning models, making it efficient for embedded AI devices like JetBot.

---

# 🚀 Features

- Real-time motion detection
- Hand-guided robot navigation
- Lightweight OpenCV implementation
- Smooth differential motor control
- Optimized for Jetson Nano 2GB

---

# 🧠 Working Principle

1. Capture live camera feed
2. Convert frames to grayscale
3. Compare current frame with reference frame
4. Detect scene changes caused by hand motion
5. Determine whether motion occurred on LEFT or RIGHT side
6. Navigate robot accordingly using differential motor control

# 📦 Installation

## Clone Repository

```bash

```

## Install Requirements

```bash
pip3 install -r requirements.txt
```

## Run Project

```bash
python3 hand_guided_navigation.py
```
